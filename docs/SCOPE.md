# Project Scope: Kak Maziar (English Teacher Platform)

## Goal

A full-stack platform for an English teacher to manage private students, conduct placement tests, and sell digital materials. Built as a resume portfolio (Laravel 12 API + React SPA + Filament v4).

## In Scope (MVP)

1. Public Pages: Home, About, Articles, Podcasts, Favorites.
2. Auth: Sanctum SPA (Login/Register).
3. Placement Test: 30 Questions -> English Passport Card.
4. Booking System: Request -> Propose Time -> Confirm.
5. Teacher Dashboard (Filament): Manage students, test results, times.
6. Shop: Digital files (Ebooks, Worksheets) with secure download.

## Out of Scope

- Real-time video calls (Zoom).
- Automated payment gateways (Manual only).
- Multi-language (English only).
